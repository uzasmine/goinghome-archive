# 라벨 실내악 라벨링 하기 · 칼럼 아카이브

고잉홈프로젝트(Going Home Project)의 라벨 실내악 전곡 앨범 발매를 기념한 칼럼 8편을 모아 둔 웹사이트입니다.
서버나 데이터베이스가 없는 가벼운 정적 사이트라서, 파일만 고치면 사이트가 바뀝니다.

---

## 폴더 구성

```
goinghome-archive/
├── index.html            ← 사이트 화면 전체 (디자인과 동작)
├── content/
│   ├── columns.json      ← 칼럼 목록: 제목, 표지, 연주자, 유튜브 링크
│   ├── 01.ko.txt         ← 01번 칼럼 한국어 본문
│   ├── 01.en.txt         ← 01번 칼럼 영어 본문
│   └── …                 ← 02~08번도 같은 방식
└── assets/
    ├── cover-01.webp …   ← 칼럼 표지 (카드뉴스 첫 장)
    ├── album-1.webp …    ← 앨범 아트
    ├── title.png         ← 메인 제목 액자 이미지
    ├── logo.png          ← 흰색 로고
    ├── og.jpg            ← 카톡·인스타에 링크를 붙였을 때 뜨는 미리보기 이미지
    ├── favicon.png       ← 브라우저 탭 아이콘
    └── fonts/            ← 프리텐다드 폰트 (SIL Open Font License, 무료 사용 가능)
```

**글이나 곡 정보를 고칠 때는 `content/` 폴더만 보면 됩니다.** `index.html`은 디자인을 바꿀 때만 엽니다.

---

## 자주 하는 일

### 1. 칼럼 본문 오타 고치기

1. GitHub에서 저장소를 열고 `content/` → 고칠 파일(예: `03.ko.txt`)을 누릅니다.
2. 오른쪽 위 연필 아이콘(Edit)을 누르고 글을 고칩니다.
3. 아래 **Commit changes** 버튼을 누릅니다.
4. 1~2분 뒤 사이트에 자동으로 반영됩니다.

본문 작성 규칙:
- 문단과 문단 사이는 **빈 줄 하나**로 구분합니다.
- 인용문은 줄 맨 앞에 `> ` (꺾쇠 + 띄어쓰기)를 붙이면 따로 강조돼서 보입니다.
- 이모지나 서식 기호(굵게 등)는 쓰지 않습니다. 글자 그대로 나옵니다.

### 2. 새 칼럼 추가하기 (예: 09번)

1. **표지 이미지**를 `assets/cover-09.webp`(또는 .jpg)로 올립니다. 카드뉴스와 같은 4:5 비율이면 됩니다.
2. **본문**을 `content/09.ko.txt`, `content/09.en.txt` 두 파일로 올립니다. 영어가 아직 없으면 한국어를 그대로 넣어 두고 나중에 바꿔도 됩니다.
3. `content/columns.json`을 열어, 마지막 칼럼의 `}` 뒤에 쉼표를 찍고 아래 형식을 붙여 넣은 뒤 내용을 바꿉니다.

```json
{
  "no": 9,
  "cover": "assets/cover-09.webp",
  "kicker": { "ko": "표지의 한 줄 소개", "en": "One-line intro" },
  "title": { "ko": "곡 제목 전체", "en": "Full title" },
  "short": { "ko": "짧은 제목", "en": "Short title" },
  "work": "영문 곡명 (재생 바에 표시)",
  "performers": "연주자 A · 연주자 B",
  "movements": true,
  "tracks": [
    { "title": "I. 첫 악장", "youtube": "유튜브영상ID" },
    { "title": "II. 둘째 악장", "youtube": "유튜브영상ID" }
  ],
  "video": "연주영상ID"
}
```

- `movements`: 악장이 여러 개면 `true`. 단악장이면 이 줄을 지웁니다.
- `video`: 연주 영상이 없으면 이 줄을 지웁니다. (지울 때 바로 윗줄 끝의 쉼표도 함께 지워야 합니다.)
- **유튜브 영상 ID 찾는 법:** `https://youtu.be/dF_LxLJ4v_w?si=...` 에서 `youtu.be/` 바로 뒤, `?` 앞까지의 글자(`dF_LxLJ4v_w`)입니다.

> ⚠️ `columns.json`은 쉼표·따옴표·괄호 하나만 틀려도 전시 전체가 안 뜹니다. 저장 후 사이트에 "전시를 불러오지 못했어요"가 보이면 방금 고친 부분의 쉼표와 따옴표를 확인하세요. https://jsonlint.com 에 내용을 붙여 넣으면 틀린 줄을 알려 줍니다.

### 3. 메인 화면 문구·앨범 링크 바꾸기

`index.html`을 열어 `const T =` 부분(화면 문구)과 `const ALBUMS =` 부분(앨범 링크)을 고칩니다. 한국어(`ko`)와 영어(`en`)가 나란히 있습니다.

## 처음 온라인에 올리기 (한 번만)

1. **GitHub**에서 새 저장소(Repository)를 만듭니다. 이름 예: `goinghome-archive`, 공개(Public).
2. 저장소 첫 화면의 **uploading an existing file** 링크를 누르고, 이 폴더 **안의 내용 전체**(index.html, content, assets, README.md)를 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
3. **Vercel**에 로그인 → **Add New… → Project** → 방금 만든 저장소 옆 **Import** → 설정은 건드리지 않고 **Deploy**.
4. 1분 정도 뒤 `https://goinghome-archive.vercel.app` 같은 주소가 생깁니다.
5. 그 주소를 받으면 `index.html`의 `og:url`, `og:image` 줄에 그 주소를 넣습니다. (이 사이트는 이미 `https://goinghome-archive.vercel.app`으로 설정되어 있습니다. 나중에 주소가 바뀌면 이 두 줄도 바꿔 주세요.)

이후에는 GitHub에서 파일을 고칠 때마다 Vercel이 **자동으로** 다시 올립니다.

### 나만의 주소 연결하기 (선택)

오케스트라 도메인이 있다면 Vercel 프로젝트 → **Settings → Domains**에서 `archive.도메인.com`처럼 추가하고, 안내에 나오는 값을 도메인 관리 사이트(가비아, 카페24 등)에 입력하면 됩니다.

## 알아 두면 좋은 점

- **음악 재생은 유튜브를 사용합니다.** 유튜브 채널에 광고가 켜져 있으면 곡 앞에 광고가 나올 수 있습니다.
- **처음 재생할 때 플레이어 창이 펼쳐집니다.** 유튜브 규칙상 플레이어가 화면에 보여야 하기 때문입니다. 방문자가 원하면 접을 수 있습니다.
- **일부 아이폰에서는** 첫 재생 시 펼쳐진 영상의 ▶를 한 번 직접 눌러야 할 수 있습니다. 그런 경우 화면에 안내 문구가 자동으로 뜹니다.
- 여러 악장으로 된 곡은 한 악장이 끝나면 **다음 악장으로 자동으로** 넘어갑니다.
- 칼럼 주소는 `사이트주소/#c03`처럼 칼럼마다 따로 있어서, 특정 칼럼만 공유할 수 있습니다.
- 영어 본문은 **번역 초안**입니다. 영어판 상단의 "Translation draft · under review" 표시는 검수가 끝나면 `index.html`의 `draft: "Translation draft · under review"`를 `draft: ""`로 바꾸면 사라집니다.

## 방문자 수 보기

Vercel 대시보드 → `goinghome-archive` 프로젝트 → 위쪽 **Analytics** 탭에서 볼 수 있습니다.
방문자 수, 페이지 조회 수, 어느 나라·어떤 기기(휴대폰/PC)에서 왔는지, 어디서 링크를 타고 왔는지(인스타그램 등)가 나옵니다.

- 처음 한 번은 Analytics 탭에서 **Enable**을 눌러 켜야 합니다. (`index.html`에는 이미 필요한 코드가 들어 있습니다.)
- 무료(Hobby) 플랜은 한 달에 기록할 수 있는 양에 한도가 있습니다. 이 정도 규모의 사이트라면 보통 충분합니다.
- 칼럼별 조회 수는 따로 나뉘지 않고 사이트 전체로 합쳐서 보입니다.
